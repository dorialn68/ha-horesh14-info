# החורש 14 — אתר מידע ציבורי

האתר נבנה כגרסה סטטית המתאימה ל־GitHub Pages. הקובץ הראשי הוא `index.html`.

## פרטיות

הגרסה הציבורית אינה כוללת שמות משלמים, מספרי חשבון, מספרי טלפון או צילומי בנק. אין להוסיף לקובצי האתר מידע כזה: GitHub Pages אינו מספק הזדהות מאובטחת לפי שם משפחה או טלפון.

## פרסום

לאחר בדיקה ואישור של הנוסח, ניתן לפרסם את תוכן התיקייה בשורש מאגר GitHub ולהפעיל Pages מהענף הראשי. לפני פרסום יש להחליט אם האתר יהיה ציבורי ולהבין שכל הקבצים במאגר ציבורי ניתנים להורדה.

## עדכון נתונים

האתר נוצר באמצעות כלי מקומי שאינו נכלל במאגר. הגרסה הציבורית מציגה סכומים, תאריכים וסיווגים ללא שמות מקבלים או משלמים וללא מסמכי מקור המכילים פרטים אישיים.
